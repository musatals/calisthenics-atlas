Progression maps

Skill pathways

Use these example sequences as flexible guides, not rigid prerequisites.

Push

Push-up pathway

Wall push-up → Incline push-up → Floor push-up → Decline push-up.

Pull

Pull-up pathway

Active hang → Scapular pull-up → Assisted pull-up → Pull-up.

Lower body

Single-leg pathway

Squat → Split squat → Supported single-leg squat → Pistol squat.

Core

Trunk control

Dead bug → Hollow hold → Tuck support → Tuck L-sit.

Balance

Handstand preparation

Plank → Pike hold → Wall handstand → Freestanding balance practice.

Advance when repetitions feel controlled and repeatable. Use appropriate support and a safe training environment.
