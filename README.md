# Calisthenics Atlas

A responsive, dependency-free educational website about bodyweight training.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit http://localhost:8000.

## Deploy

**Vercel:** Import the repository, select Framework Preset **Other**, leave Build Command empty, and use the repository root as Output Directory.

**GitHub Pages:** Push the files to the default branch and enable Pages from the root directory in repository settings.

## Structure

- `index.html`: homepage
- `exercises.html`: searchable exercise library
- `pathways.html`: skill progression pathways
- `articles.html`: article index
- `articles/`: six editorial guides
- `science.html`: science and safety
- `about.html`: mission and roadmap
- `styles.css`, `script.js`: site-wide design and interactions

## Editorial note

This is a starter educational project. Exercise guidance should be reviewed by qualified subject-matter experts before presenting it as authoritative medical or sports-science advice.
